# 2025-F1-Point-Mass-Lap-Time-Simulator
Python-based Lap-time point-mass laptime sumulator of a 2025 F1 car travelling around a superspeedway-style track. Models lift, drag, tire friction coefficient, and variable power across the rev range. Utilizes bisection method to optimize braking points. Currently being developed to add quasi-static physics while reducing computational cost.
